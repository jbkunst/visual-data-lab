# Draw the Data

A fitted regression line is a useful summary, but it is not a picture of the data.

This guided story starts each chapter with only a few numerical summaries. Pause and imagine the dataset, then press **Draw the data** to reveal the observations.

The six chapters show:

1. a relationship that behaves as expected;
2. a nonlinear pattern hidden by a straight line;
3. a result supported by influential observations;
4. separate clusters mixed into one global trend;
5. changing uncertainty around the same average direction;
6. Simpson's paradox after revealing a hidden grouping variable.

The examples are generated from the Quasi-Anscombe functions in [`klassets`](https://github.com/jbkunst/klassets).
